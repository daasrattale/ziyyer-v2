# Ziyyer — Technologies

- **Framework:** Flutter 3.38.4 (managed via FVM)
- **Language:** Dart SDK ^3.10.3
- **Local Database:** Drift (SQLite ORM) — reactive streams, compile-time checks
- **Navigation:** go_router (declarative routing)
- **UI:** Google Fonts, Feather Icons, Lucide Icons, custom theme
- **State/Reactivity:** rxdart (combineLatest for multi-table streams)
- **Platforms:** Android, iOS, Web, macOS, Linux, Windows
- **CI/CD:** GitHub Actions — build, test, release via `scripts/`
- **Codegen:** build_runner + drift_dev
- **Linting:** flutter_lints
